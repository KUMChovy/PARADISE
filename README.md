# Nombre del proyecto: Agencia PARADISE
Proyecto para la agencia de vieajes "PARADISE", gestion usuarios, viejes nacionales e internacionales 

# Objetivo 
Desarrollar una aolicacion web para la agencia de viajes "PARADISE" en un periodo de tiempo de 4 meses con la metdologia SCRUM y HTML, CSS, JS Y SQL

# Funcionalidades 

- [] Gestion de usuarios
- [] Gestion de vieajes nacionales
- [] Gestion de viajes internacionales
